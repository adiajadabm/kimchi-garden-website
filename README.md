# Kimchi Garden website prototype

A design concept by Adia for a website for Kimchi Garden, a Korean restaurant in Berkeley, CA.

**This is not the official Kimchi Garden website and is not affiliated with the restaurant.** Nothing here places a real order or takes a payment.

## What's inside

- A vintage Korean-flyer look with a neon sign and a real-time 3D bibimbap (three.js)
- The full menu, with a demo cart and checkout
- A "What should I eat?" order helper
- Reviews, hours and a live map

## Placeholders

- Dish photos are AI-generated.
- All but one review are marked samples.
- Menu, prices and hours come from the restaurant's Yelp listing and aren't confirmed by the restaurant.
- The delivery fee and tax rate are placeholders.

## Try it

Open `prototype/index.html`, or run `python3 -m http.server 8123` inside `prototype/`. Add `?tune` to the address, or press Shift+T, for the 3D tuning panel.

`prototype/DEPLOY.md` explains how real payments, live reviews and the AI helper would be switched on. API keys belong in the host's settings, never in this repo.
